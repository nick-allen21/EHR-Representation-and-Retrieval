## Implementation

All plots are generated by a single standalone script:

```bash
conda run -n ehr python scripts/generate_plots.py                  # both datasets
conda run -n ehr python scripts/generate_plots.py --dataset dev     # dev only
conda run -n ehr python scripts/generate_plots.py --dataset verified
```

Output goes to `data/results/plots/dev/` (200-patient dev set) and `data/results/plots/verified/` (70-patient verified set). The script reads from `summary.json`, `judge_rankings.json`, per-question result files, and `model.pkl` / `feature_extractor.pkl`.

**Key file:** `scripts/generate_plots.py`

## Key Findings Illustrated

**Plot 1 (Efficiency Scatter):** Learned and semantic RAG cluster in the lower-left (low tokens, high quality), while full-context and recency use 3–4x more tokens. On the verified set, learned achieves ~95% of discharge-only quality with ~1/3 the tokens.

**Plot 9 (Feature Group Breakdown):** Section × question-type interactions dominate the weight mass (~79% of active weight), confirming the model learns *where* information appears in a note, not just lexical similarity. This is the key differentiator vs semantic RAG.

**Plot 10 (Model Lift):** Phi-3-mini-4k gets the largest lift from learned selection. The smaller the model's context window, the more it benefits from intelligent chunk selection.

**Plot 12 (Win Rate):** Learned selector beats full-context on 30–45% of questions across models (judge score), showing consistent per-question improvement, not just mean improvement.
